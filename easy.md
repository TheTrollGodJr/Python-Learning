# Easy Difficulty Programming Projects

## Rock, Paper, Scissors

Psuedo-code of the game logic:

1. Get player input using input() function
2. Use if statement to check if the player entered 'rock', 'paper', or 'scissors'
3. In each if statement, print what beats the players choice
- if the player enters rock, print paper

[*How to use the input() function*](https://www.w3schools.com/python/ref_func_input.asp)

## Dice roller/Random number generator

Psuedo-code for the programs logic:

1. Get user input using input()
- get the minimum and maximum values to randomize
- eg. user inputs 1 and 5. The program chooses a random number between 1 and 5
2. Generate the random value
- Use random.randint() from the 'random' package
3. print the random value

*Note: use the 'random' package built into python*

## Basic Terminal Calculate

Psuedo-code for the programs logic:

1. Ask the user what operation they want to use (using input())
- +, -, /, //, *, **, %
2. Get two numbers from the user (using input())
3. Create functions for each math operation
- The function should take both numbers from the user as parameters
- The function should return the output of the math operation between the two parameters
4. Use if statements to choose which math function to run
5. Print the return value
