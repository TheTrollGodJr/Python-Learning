# Installing Python

[Python.org](https://www.python.org/downloads/)
[Python 3.14.2 install link](https://www.python.org/ftp/python/3.14.2/python-3.14.2-amd64.exe)
*You may want to install the standalone installer rather than install manager*
*The link above is a download for the Python version 3.14.2 standalone installer*
*Python 3.14.2 is the latest release as of writing*
When you open the installer, select checkbox to add python.exe to PATH
The default installation option should work for most needs

[Video Tutorial](https://www.youtube.com/watch?v=C3bOxcILGu4)

To write code you want to choose a code editor 
There are plenty of code editors to choose from
[Visual Studio Code](https://code.visualstudio.com/download) is an easy to use IDE for beginners
